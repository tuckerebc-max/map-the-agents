## Description

Highlight (site page `what_makes_it_special`): Not a coding tool itself — a curated awesome-list comparison directory of AI coding tools that provide free access to pro-grade models (Claude Opus/Sonnet, GPT-5, Gemini Pro, Qwen3-Coder, etc.). Standardizes the definition of 'pro-grade' using SWE-bench Verified (\>=60%) and places all tools side-by-side with actual free-tier limits, making hard-to-compare quotas directly comparable.

(captured site page body (agents/free-ai-coding.md), not a verified repo-code finding)
Free tiers of AI coding tools advertise wildly different quota schemes, making it hard to tell which actually give meaningful access to frontier models. This repository defines pro-grade as at least 60% on SWE-bench Verified and maintains a side-by-side table of what each qualifying tool gives away for free, with per-tool entries covering request limits and model availability. The list is generated from data files and scripts rather than hand-edited markdown, and published in eight languages. Its audience is developers and students choosing a tool without a budget, and contributors keep it current as vendors change their quotas.
