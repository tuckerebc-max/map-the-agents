(captured site page body (agents/10x.md), not a verified repo-code finding)
10x is a terminal-based CLI coding agent (installed via npm install -g 10x-cli) built around the observation that frontier models are wasted on routine steps. Its Superpowers system defines multi-step workflows in markdown files, and a routing layer picks the fastest model tier that can handle each step, from open-weight fast models up to Claude Opus 4 for hard reasoning. Users bring their own OpenRouter key, so the tool is fully self-hostable with no vendor lock-in. It targets developers who want a Claude Code alternative with explicit control over the cost-speed-capability tradeoff per task.
