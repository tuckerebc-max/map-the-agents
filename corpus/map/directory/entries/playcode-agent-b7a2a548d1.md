## Description

Highlight (site page `what_makes_it_special`): Combines AI builder and cloud runtime in a single product; unique 'rewind' feature rolls back entire app (including database and files) to a saved snapshot in ~1 second. Users own 100% of code (React/Vue/HTML export).

(captured site page body (agents/playcode-agent.md), not a verified repo-code finding)
PlayCode Agent extends a long-running JavaScript playground (operating since 2016) into an AI app builder where the agent and the runtime are the same product: describe an app, the agent asks clarifying questions, writes React, Vue, or HTML code, and publishes it on PlayCode's EU-hosted infrastructure with backend and database attached. Snapshots capture the whole project — code, files, database — before risky changes and on demand, and rewinding restores everything in roughly a second; git history on separate infrastructure and nightly encrypted backups sit behind that first line of defense. Code ownership is unconditional: users export React/Vue/HTML projects in full and host them elsewhere if they choose. The free tier covers getting started, with Pro at $25/month adding all 12+ models, custom domains, and private projects. Its users are hobbyists and indie builders shipping small web apps, with 1.1M+ claimed users.
