(captured site page body (agents/oinone-pamirs.md), not a verified repo-code finding)
Oinone Pamirs is a Java, metadata-driven low-code framework for building enterprise applications such as MES, ERP, and OMS systems, used by over a hundred software companies. All development is expressed as metadata paired with visual no-code design, giving AI-generated code a disciplined structure to land in rather than free-form scaffolding. The bundled Aino agent platform adds model access, tool libraries, knowledge bases, and orchestration to applications built on the framework. A data-feedback loop supports a self-evolving application lifecycle from training through autonomous execution. The backend is AGPL-3.0 with an enterprise edition available, and deployment is a one-command Docker Compose stack.
