## Description

Highlight (site page `what_makes_it_special`): Repo-native autonomous software engineering platform

(captured site page body (agents/solver.md), not a verified repo-code finding)
Solver, by Laredo Labs, marketed itself as delegation rather than assistance: developers submitted multi-step tasks through an API or IDE integration, and the service worked asynchronously with git, code-coverage tooling, and external documentation to produce reviewable output, billing per step via credits (a free 50-credit tier and a $20 Pro plan at launch). Its stated differentiation was repository-based reasoning plus proprietary models trained on its own engineering corpus. The founders came from Siri and Viv, and the pitch framed coding capacity as an elastic utility rather than an editor feature. The live site no longer resolves — solverai.com now returns a 404 error page — and the most recent Wayback capture is from August 2025, so the product should be treated as defunct.
