## Description

Highlight (site page `what_makes_it_special`): An orchestration layer / desktop client that runs coding agents (Claude Code, Codex) locally or in the cloud with a Cursor-like visual UI: diff previews, real-time tool execution, per-chat git worktree isolation, background cloud sandboxes that run while your laptop sleeps, live browser previews, a kanban board for agent sessions, a built-in git client, an MCP plugin marketplace, GitHub/Linear/Slack automations, ...

(captured site page body (agents/1code.md), not a verified repo-code finding)
1Code came from the 21st.dev team as a desktop and web front end for the era of terminal coding agents: Claude Code and Codex run as engines while the app provides diff previews, a built-in git client, plan mode with clarifying questions, and isolated worktrees per chat. Background agents run in cloud sandboxes that outlive a closed laptop, with live browser previews, and GitHub, Linear, Slack, or git events can trigger agent runs; an API opens a sandbox and returns a PR. The Electron app was free to build from source while pre-built releases and background agents sat behind Pro/Max subscriptions, and the repository (5.6k stars) was archived read-only on July 7, 2026.
