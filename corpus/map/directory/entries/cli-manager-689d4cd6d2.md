## Description

Highlight (site page `what_makes_it_special`): Unified dashboard for managing multiple CLI-based coding agents (Claude Code, Codex CLI, Gemini CLI) from a single native macOS app. Features Git worktree integration, port tracking, terminal templates, role/nickname assignment, instant editor switching, and split view. Apple notarized, all processing local.

(captured site page body (agents/cli-manager.md), not a verified repo-code finding)
CLI Manager targets the operational overhead of running several agents across several projects: instead of remembering which terminal holds which worktree and which port each dev server occupies, the dashboard lists agents with roles and status, organizes worktrees, and flags port conflicts before they bite. Any CLI tool can be registered, so there is no vendor coupling, and editor hand-off is one click. Privacy is local-only with no telemetry, and the app is Apple-notarized. It reached #10 Product of the Day on Product Hunt, is open source under MIT, free for core features, and actively developed with a public roadmap.
