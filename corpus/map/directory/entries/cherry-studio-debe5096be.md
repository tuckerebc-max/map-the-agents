Cherry Studio is a cross-platform desktop AI client built on Electron that consolidates access to many model providers behind one interface: OpenAI, Anthropic, Gemini, Perplexity, Poe, and local models through Ollama and LM Studio, with preconfigured assistants for common tasks. Its feature set covers multi-model simultaneous conversations, document and image processing, web search integration, translation, a mini-app framework, and MCP server connectivity for external tools, with data stored locally and backup via WebDAV. The project is open source under AGPL-3.0, with a commercial enterprise edition sold separately, and one of the largest communities among desktop AI clients (over 50,000 stars and an active release cadence). Its audience is individual users and teams who want a unified, private front end across many providers rather than a coding tool; a plugin system and MCP marketplace remain on the roadmap.
