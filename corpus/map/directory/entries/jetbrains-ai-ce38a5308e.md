## Description

Highlight (site page `what_makes_it_special`): Deep integration of AI features with code understanding and core IDE workflows. Ecosystem includes AI Assistant (assistive), Junie (autonomous coding agent), and Grazie (writing companion). Supports bring-your-own-key (BYOK) for OpenAI and Anthropic, local models via Ollama/LM Studio, on-premises LLMs via Hugging Face. Agent Client Protocol (ACP) enables third-party agents (Claude, Codex, Gemini CLI, Cursor, GitHub Copilot). Enterprise-ready with on-premises, cloud, ...

(captured site page body (agents/jetbrains-ai.md), not a verified repo-code finding)
JetBrains ships AI as IDE-integrated tiers rather than a standalone app: AI Assistant handles completion, chat, and inline transformations; Junie executes multi-step coding tasks autonomously; Grazie handles prose. Mellum, JetBrains' own code model, anchors the stack alongside OpenAI, Anthropic, Google, xAI, and Bedrock models, with BYOK and locally hosted Ollama/LM Studio models supported. The Agent Client Protocol is the differentiator — Claude, Codex, Gemini CLI, and other external agents can run inside JetBrains IDEs through ACP rather than being locked to first-party features. Pricing runs from a free tier to AI Pro ($100/user/year), AI Ultimate ($300), and AI Enterprise ($720), with enterprise on-premises and hybrid options.
