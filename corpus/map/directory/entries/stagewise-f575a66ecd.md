## Description

Highlight (site page `what_makes_it_special`): Agentic IDE for open-source models — browse and build in same tool without context switching; coding agent with full access to console and debugger; reverse-engineer any website's components/styles/palettes; bring-your-own-key for all major AI providers including local inference; 345+ models via OpenRouter.

(captured site page body (agents/stagewise.md), not a verified repo-code finding)
Stagewise combines a browser and a coding agent in one window so that building and testing stay in one place: the agent has full access to the rendered page's console and debugger, so a suggested fix is executed against the running app rather than guessed at. Developers can prototype on throwaway changes or connect a codebase for permanent edits, with changes surfaced in the IDE for review and application, and any site's components, style system, and palette can be reverse-engineered as a starting point. Model access is BYOK across Anthropic, OpenAI, Google, xAI, and local inference, plus one-click import of Kimi, Qwen Coding Plan, MiniMax, and Xiaomi MiMo subscriptions and 345+ models through OpenRouter. Stagewise GmbH offers free, $20 Pro, and $200 Ultra tiers, and the AGPL-3.0 codebase is actively developed.
