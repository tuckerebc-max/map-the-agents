## Description

Highlight (site page `what_makes_it_special`): Dataset of coding agent interactions captured from real users in the wild (not synthetic or benchmark-generated), providing authentic in-the-wild interaction data for research. Pre-release; data and code stated as coming soon.

(captured site page body (agents/swe-chat.md), not a verified repo-code finding)
SWE-chat is a dataset project from the SALT-NLP group aiming to fill a specific gap: there is very little published data on how real developers actually converse with coding agents, since most corpora are synthetic or benchmark-derived. The repository is currently a placeholder — MIT license plus a README promising that data and code are coming soon — with the intended distribution on Hugging Face and an accompanying arXiv paper and project site already linked. Because the transcripts have not yet been published, neither the collection methodology nor the schema can be verified from the repository itself. Researchers studying human-agent interaction patterns in software engineering are the declared audience, and the project's value will depend on the eventual data release.
