## Description

Highlight (site page `what_makes_it_special`): Opinionated, batteries-included Next.js 14 full-stack template explicitly optimized for AI coding assistants (especially Cursor). Includes agent-helpers folder (tasks, scratchpad, logs), .cursorrules, custom Cursor slash commands (/start, /continue, /review, /document, /refactor), and a task-checklist-driven workflow for AI agents.

(captured site page body (agents/next-ai-starter.md), not a verified repo-code finding)
next-ai-starter is a batteries-included Next.js 14 template — TypeScript, tRPC, Prisma, NextAuth, Supabase, Tailwind, Storybook, Inngest, Resend — assembled specifically so AI coding agents such as Cursor can build on it effectively. The agent-helpers folder gives the agent a place to track tasks, jot scratch work, and write logs, while .cursorrules and custom slash commands structure how the agent plans, executes, and reviews work. The author distributes it as a personal template tied to his AI coding tutorials and explicitly declines feature pull requests, so users fork and adapt it rather than contribute upstream. Adoption is measured in the hundreds of forks using it as a starting point for AI-assisted full-stack projects.
