## Description

Highlight (site page `what_makes_it_special`): Platform to create, manage, and embed custom AI chatbots with natural language processing and features like call-to-actions, link carousels, and analytics

(captured site page body (agents/libraria.md), not a verified repo-code finding)
Libraria serves businesses that need customer-facing or internal chatbots without building agent infrastructure: teams compose bots in a visual platform, connect their content, and embed them in sites or products with features like call-to-actions, link carousels, and conversation analytics. The platform handles the natural-language layer, and embeds target support, sales, and information-delivery use cases rather than software development. There is no tool loop that creates or modifies software, which places it outside the coding-agent census as a chatbot-builder platform.
