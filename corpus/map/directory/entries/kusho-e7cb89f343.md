## Description

Highlight (site page `what_makes_it_special`): AI-powered software reliability and testing platform (not a coding agent); domain-grounded AI orchestration trained on real testing data; self-maintaining reliability infrastructure that auto-updates tests when API contracts drift; release intelligence with AI-computed risk scores.

(captured site page body (agents/kusho.md), not a verified repo-code finding)
Kusho targets the gap between code generation and production reliability: QA and platform teams need suites that track API contracts as they change rather than one-time generated tests. Pointing it at an OpenAPI spec or Postman collection produces a test suite checked against every contract change; continuous security scanning runs in CI against live APIs; self-healing tests update themselves as contracts drift. A release intelligence layer scores each release from changes, test results, and failure history to support go/no-go decisions. Claimed adoption spans 5,200+ organizations across fintech, logistics, e-commerce, healthcare, and oil and gas, with a free tier and paid plans above it.
