GraphQL Playground is a graphical IDE for writing and testing GraphQL queries, built by the Prisma and GraphQL community on top of GraphiQL components. It adds context-aware autocompletion, error highlighting, real-time subscription support, an interactive multi-column schema explorer, query history, tabbed sessions, and configurable HTTP headers, and it ships as a desktop app, an embeddable React component, and middleware for Express, Hapi, Koa, and Lambda servers. Throughout the late 2010s it served as the default query IDE for many GraphQL toolchains. The project was archived on May 4, 2026, with the repository read-only and development consolidated into GraphiQL.
