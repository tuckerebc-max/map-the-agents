## Description

Highlight (site page `what_makes_it_special`): No-code platform for hosting AI agents in cloud workspaces with persistent private computers. One-click launch with kernel-level isolation and encryption. Model-agnostic with BYOK support. Targeted at non-technical users.

(captured site page body (agents/mantlecore-ai.md), not a verified repo-code finding)
Mantlecore packages what usually requires Docker, GPUs, and API plumbing into a browser-delivered workspace: subscribers pick a plan sized by vCPU and RAM, and the platform boots a persistent machine with Agent Zero or Hermes Agent preinstalled, daily backups, and snapshots. The agents browse, write and run code, install dependencies, run tests, and maintain memory across sessions, aimed at research, content, data analysis, and software tasks. Model access is OpenAI, Anthropic, Gemini, Grok, DeepSeek, Mistral, Kimi, or local Ollama, billed separately from the plan, with new accounts receiving $2 in credit. It targets non-technical users and small teams who want agent outcomes without operating infrastructure.
