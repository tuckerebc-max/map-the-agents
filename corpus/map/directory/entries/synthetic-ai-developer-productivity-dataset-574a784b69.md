The repository publishes a 5,000-record synthetic dataset generated by Syncora.ai's data-generation product, intended for productivity prediction, burnout detection, and feature-engineering practice without the privacy exposure of real employee telemetry. Each row describes one developer-day across ten columns — focus hours, meetings, lines of code, commits, task completion rate, reported burnout, debugging time, stack complexity, pair programming, and a composite productivity score — and a Jupyter notebook demonstrates loading and exploration. It contains no software, no agent loop, and no tool use; its relation to coding agents is thematic, capturing 'AI developer' behavior patterns rather than agent mechanics. The absence of a license file means formal reuse rights are unresolved, and the dataset primarily serves as a demonstration artifact for Syncora.ai's synthetic-data engine.
