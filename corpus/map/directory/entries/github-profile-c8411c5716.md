(captured site page body (agents/github-profile.md), not a verified repo-code finding)
The aiwaves-cn organization is best known for the 'agents' framework, a research system for building autonomous language agents whose distinguishing idea is symbolic learning: agent runs are recorded as trajectories, evaluated by a language-defined loss, and improved by back-propagating language gradients through prompts, tools, and the agent's computation graph. This makes the framework self-evolving in a way most pipeline libraries are not, though its output is better prompts and workflows, not source code. The v2.0 release and accompanying arXiv paper landed in June 2024, and the repository has been largely dormant since, with open issues untriaged. It is studied as a research artifact on self-evolving agents rather than used as production tooling.
