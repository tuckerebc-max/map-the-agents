## Description

(captured site page body (agents/hostinger-horizons.md), not a verified repo-code finding)
Hostinger Horizons is a hosted, no-code application builder aimed at people who describe software rather than write it. A prompt, template, or existing URL produces a working web application with an integrated backend, database, user accounts, and file storage, then refinement happens conversationally, in a visual editor, or through direct code editing. Commerce and analytics features (Stripe, PayPal, AdSense, Meta Pixel, WhatsApp) are built in, so generated apps launch without wiring external services, and a template marketplace lets creators earn from remixes. The service is bundled with Hostinger hosting plans rather than sold separately, with AI generation metered through credits per tier. Its users are entrepreneurs and small businesses building stores, booking systems, and internal tools rather than engineering teams.
