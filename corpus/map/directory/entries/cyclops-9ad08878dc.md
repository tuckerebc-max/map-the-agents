## Description

Highlight (site page `what_makes_it_special`): AI coding agent orchestration: dispatch agents to implement issues

(captured site page body (agents/cyclops.md), not a verified repo-code finding)
Cyclops is a JetBrains plugin for developers who want to delegate implementation work to AI agents without leaving their IDE. It dispatches agents such as Claude, Gemini, and Codex to implement tracked issues, keeps a run history of what each agent did, and lets users store reusable skills that shape how agents approach recurring tasks. A built-in issue tracker and an 'ideas sketch' capture round out the loop from thought to delegated implementation, and the plugin can also generate LLM-powered research reports. It is free, MPL-2.0 licensed, and published by a solo developer, with about 100 downloads since August 2026 — an early-stage tool for JetBrains-centric workflows.
