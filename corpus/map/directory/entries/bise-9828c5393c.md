bise is a multi-agent harness for people who would rather brief one agent than supervise five: you talk to the lead (main), it splits what you ask into tasks, does the small ones itself, and starts an agent per task when one is needed. The agents work in parallel in your checkout, message each other before touching the same files, and take an automatic git worktree when one needs its own copy — no branches to name, no folders to clean up. What needs you (approvals, choices between options, merges) waits in one inbox, and agents ask the lead rather than you, so only the decisions that are actually yours arrive. The hub that keeps the state of every agent and message runs locally, its sb-core message layer written in the Bend language with checked laws and proofs (no message lost or delivered twice, a restart rebuilds the same state), and each agent's loop runs in bise's own runtime, where agents write small TypeScript scripts to call several tools in one step.
