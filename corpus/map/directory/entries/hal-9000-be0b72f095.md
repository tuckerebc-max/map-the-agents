## Description

Highlight (site page `what_makes_it_special`): Opinionated AI coding agent and dev environment automation for macOS; bootstraps full dev setup including Claude Code plugins (hal-session-auto-rename, hal-voice, hal-statusline), Codex config, and dev toolchains; dotfiles hardened against supply chain attacks; CLI (hal) for managing environment via Ansible roles

(captured site page body (agents/hal-9000.md), not a verified repo-code finding)
hal-9000 is an opinionated, self-hosted setup that turns a Mac into a configured AI development workstation. An Ansible-driven bootstrap script installs toolchains (Python, Node, Bun, Docker, Kubernetes, cloud CLIs), hardens dotfiles and agent settings against supply-chain attacks, and lays down global CLAUDE.md and AGENTS.md instruction files alongside Codex configuration. On top of the environment sit custom skills — commit conventions, over-engineering prevention, blindspot review, plain-English writing — plus Claude Code plugins for session renaming, voice feedback, and a statusline, all installable through the Claude Code plugin marketplace. The hal CLI manages ongoing updates, dotfile symlinking, and backup through Dropbox. It suits developers who want a reproducible, security-conscious baseline for Claude Code and Codex rather than assembling configs from scratch.
