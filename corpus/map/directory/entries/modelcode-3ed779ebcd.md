## Description

Highlight (site page `what_makes_it_special`): AI legacy code modernization at scale

(captured site page body (agents/modelcode.md), not a verified repo-code finding)
ModelCode targets migrations that defeat one-shot AI generation and exceed manual capacity: Python 2.7 to 3.12 across half a million lines, AngularJS to React and TypeScript, Ada 2012 to C++20. Its Morph workflow begins with planning that produces an editable Project Spec — architecture map, milestone sequence, acceptance criteria — which the customer's team approves before any code changes. Execution then runs as parallel, independently reviewable milestones delivered as pull requests, each gated by functional verification proving behavioral parity between original and migrated code, automated review for broken contracts and missed call sites, and explicit acceptance criteria; expected credit cost is shown before each milestone is approved. ModelDaemon, a self-hosted execution agent, runs checkouts, builds, tests, and application runs inside the customer's infrastructure over outbound-only connections, requiring no VPN or firewall changes for private repositories. Enterprises with compliance constraints use it for language upgrades and framework migrations under usage-based pricing — 40,000 credits included monthly, $0.01 per additional credit, no seat fees — with SOC 2 Type 2 and ISO 27001 certifications supporting regulated deployments.
