## Description

Highlight (site page `what_makes_it_special`): Native Grok for JetBrains with agentic mode via Grok Build CLI

(captured site page body (agents/intellego-grok-ai-assistant.md), not a verified repo-code finding)
Intellego positions itself as the Grok experience inside JetBrains rather than a multi-model wrapper: chat, selection actions (Explain, Review, Refactor, Debug), and an agentic mode that launches the official Grok Build CLI headless against the project with job logs, an optional git branch, and a hard kill button. Project context can move into xAI's Grok Collections and Project Radar instead of pasted dumps. Setup is deliberately gentle — one-click demo access without a console key, connection tests, no warning banners — while xAI bills usage directly. The plugin is externally paid: free chat plus an Intellego Premium subscription (pitched as about a coffee a month) unlocks Collections, Radar, and agentic mode.
