## Description

Highlight (site page `what_makes_it_special`): Site shows 'Deployment Paused' — product is not currently operational. Originally described as an AI-powered IDE that teaches programming concepts in real-time as you build software.

(captured site page body (agents/contral.md), not a verified repo-code finding)
AI coding tools produce working code that many users cannot explain, which matters for students, self-taught developers, and juniors who must defend their work in interviews or reviews. Contral embeds instruction into the build process: its Build Mode runs a repo-aware agent that reads, writes, and executes code while learning cards appear alongside each change explaining what was written and the tradeoffs involved. A separate Learn Mode teaches languages through structured curricula with challenges and exams (Java available; Python, JavaScript, TypeScript, Go, and Rust planned), and micro-challenges test whether the user can explain the code the agent just produced. The product ships as a VS Code extension and a standalone IDE, with a free tier and a Pro plan around $9.99 per month. Its audience is CS students, career switchers, and developers who want to understand what their tools wrote.
