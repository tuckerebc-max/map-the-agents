## Description

Highlight (site page `what_makes_it_special`): Exponent ran as both an interactive pair-programming session and a fully autonomous background worker triggered from Slack or GitHub, blurring the line between pair programmer and dispatched engineer before its org was folded into indent-com.

(captured site page body (agents/exponent.md), not a verified repo-code finding)
Exponent built an AI software engineer around the workflow where work actually arrives: a bug report in Slack or a GitHub issue could be handed to the agent, which ran in a cloud sandbox, produced a fix, and opened a pull request, with humans reviewing the diff rather than driving every step. The same harness supported interactive sessions for developers who wanted tighter control, making it usable as both a delegate and a collaborator. Its GitHub organization (exponent-run) is now deprecated with a pointer to the indent-com organization, and exponent.run returns 404 as of August 2026, indicating the product was absorbed into its parent company's stack under a new identity rather than discontinued outright.
