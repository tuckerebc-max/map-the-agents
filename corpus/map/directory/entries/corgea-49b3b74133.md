## Description

Highlight (site page `what_makes_it_special`): AI SAST with automatic vulnerability fixes

(captured site page body (agents/corgea.md), not a verified repo-code finding)
Application-security teams drown in scanner output whose false-positive rate makes remediation the actual bottleneck, and business-logic flaws slip past pattern-based rules entirely. Corgea pairs higher-signal static analysis with an autonomous agent that takes validated findings - including missing authorization checks and other logic flaws conventional scanners miss - and opens pull requests with patches for developer review. Around that core the platform covers dependency, IaC, container, and secrets scanning, SBOMs with license enforcement, and AI-driven penetration testing with auditor-ready reports, plus a registry for scanning the skills that coding agents install. Integrations span IDEs (VS Code, Cursor, JetBrains), SCM platforms, and coding agents (Claude Code, Copilot, Codex) through MCP workflows. AppSec teams use it as a Snyk or Checkmarx alternative; the product is proprietary SaaS with a 14-day Growth trial.
