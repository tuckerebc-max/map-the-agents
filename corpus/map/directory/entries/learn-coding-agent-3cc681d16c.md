## Description

Highlight (site page `what_makes_it_special`): Research and learning repository that reverse-engineers and documents the architecture of Anthropic's Claude Code CLI agent from public sources. Reveals hidden features (undercover mode, model codenames, telemetry, killswitches), 12 progressive harness mechanisms, and an unreleased future roadmap. Documentation available in four languages (EN/JA/KO/ZH). Not a tool itself -- a collection of deep analysis reports.

(captured site page body (agents/learn-coding-agent.md), not a verified repo-code finding)
The repository compiles publicly available information about how Anthropic's Claude Code agent actually works: its agent loop, 40+ tools, permission system, sub-agents, context compaction, MCP integration, and feature-flag plumbing, organized into a twelve-step educational framework for understanding harness mechanisms. Five reports cover telemetry and privacy, hidden features and codenames, an alleged 'undercover mode', remote control and killswitches, and an unreleased roadmap, with every report translated into English, Japanese, Korean, and Chinese. The author presents it as technical research and education only, disclaims commercial use, and several claims are compiled from community discussion rather than verified. It went viral (12k+ stars, heavy forking) as a controversial exposé-style resource.
