(captured site page body (agents/interactive-dev-environment-for-ai-engineers.md), not a verified repo-code finding)
This AI Maker Space repo is course onboarding material: it gets a new AI engineer from a bare machine to a working local environment. Chapters cover choosing and configuring Cursor or VS Code, OS-specific setup including WSL2 on Windows, terminal and Git fundamentals with SSH keys, and installing uv for Python environments. It then walks through securing GitHub tokens, OpenAI keys, and Anthropic keys, and finishes with first scripts, notebooks, and a branch-and-PR exercise that hands off to their follow-up AI Engineer Challenge repo. Its value is as structured onboarding; it ships no agent, harness, or code beyond the tutorial itself.
