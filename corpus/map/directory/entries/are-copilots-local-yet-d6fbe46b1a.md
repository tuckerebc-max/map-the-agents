## Description

Highlight (site page `what_makes_it_special`): Curated, community-editable list tracking the state of local LLM Copilots: editor extensions, tools, chat interfaces, models, and datasets for offline/private code AI. Includes a suggested setup guide (LM Studio + Continue.dev).

(captured site page body (agents/are-copilots-local-yet.md), not a verified repo-code finding)
Running coding copilots on local models has been an open question for privacy-conscious developers, and this repository tracks that answer over time. It curates editor extensions (Tabby, twinny, continue, localpilot), project-generation tools (gpt-engineer, gpt-pilot, aider, mentat), chat interfaces (open-interpreter, gptme), code LLMs (CodeLlama, Qwen 2.5 Coder, DeepSeek R1), and datasets, with a suggested local setup guide. Community edits flow through a data.yaml file rather than direct README edits. It is a reference list, not a tool - nothing here loops over tools or writes code. The list has lagged as the field moved quickly, though the author continues sporadic updates.
