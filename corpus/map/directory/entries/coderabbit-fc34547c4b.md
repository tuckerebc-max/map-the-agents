Highlight (site page `what_makes_it_special`): AI-driven agentic change management with Codegraph for deterministic impact mapping, Change Stack for explaining massive diffs visually, agentic review loops with coding agents, continuous learning from team preferences, customizable review profiles (Quiet/Chill/Assertive), and Triage to rank/route PRs by risk and value.

(captured site page body (agents/coderabbit.md), not a verified repo-code finding)
CodeRabbit automates code review for teams whose pull request volume exceeds human review capacity, installing as a GitHub or GitLab app that reviews every PR. Its reviews combine a deterministic code graph (Codegraph) for impact analysis with an ensemble of models, producing committable suggestions and learning each team's conventions over time so repeated feedback fades. Around review it has built adjacent products: Triage to score and route PR floods onto a P0-P3 board, Change Stack for semantic explanation of large diffs with blast-radius and architecture views, continuous security scanning with fix PRs, IDE and CLI review surfaces, and Slack integration. The platform reports 17,000 customers across six million repositories, including NVIDIA, BMW, and Swiggy, with a free tier for open-source projects.
