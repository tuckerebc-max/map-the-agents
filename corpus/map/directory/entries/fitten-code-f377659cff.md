Fitten Code is developed by Fitten Tech (非十科技), a Beijing AI company, and distributed as IDE plugins covering VS Code, JetBrains IDEs, Visual Studio, and Vim. Its feature set centers on fast code completion, chat-based generation, unit-test creation, bug fixing, and comment generation, running against Fitten's proprietary models rather than a Western provider — a positioning that has made it popular with developers who need a Copilot-class assistant with domestic data handling. The product's own website is a JavaScript-heavy application that resists static fetching, so current agentic capabilities (multi-file edits, terminal use) could not be verified from primary sources for this census. Adoption is concentrated in China, where it competes with Comate, Tongyi Lingma, and Copilot.
