## Description

Highlight (site page `what_makes_it_special`): Analyzes your codebase to produce personalized production-ready code

(captured site page body (agents/wisegpt.md), not a verified repo-code finding)
WiseGPT, from DhiWise, addresses the genericness of most AI completions: it analyzes the developer's entire codebase locally — with permission and without storing code — to learn style and conventions, then generates personalized, production-ready code with no prompting. Its chat supports @codebase to understand, plan, and implement tasks repository-wide, and its distinctive Task-to-Code feature converts tasks from Jira, Trello, Asana, and ClickUp into implemented code, an enterprise-only capability. The extension also handles Figma-to-code conversion, predefined and custom commands, and Figma import. It is free on the VS Code Marketplace (enterprise features gated), with about 32,000 installs and a 3.4.3 current version. Its users are teams working from project-management tickets who want code generated in their own conventions.
