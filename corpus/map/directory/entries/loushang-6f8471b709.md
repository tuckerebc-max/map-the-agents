## Description

Highlight (site page `what_makes_it_special`): Method-native AI work system for running complex work from intent to verified delivery. Current focus is 'loushang code', a CLI and terminal workbench for software development with model routing, persistent sessions, tools, and extensions. Treats methods, stages, roles, tools, sessions, and work products as runtime objects — making complex work reliable, recoverable, auditable, and deliverable. Method-guided delivery approach.

(captured site page body (agents/loushang.md), not a verified repo-code finding)
loushang's premise is that agent reliability comes from structure around the model, not from a smarter model. A method defines the work contract for a class of work - roles, phases, constraints, artifacts, acceptance criteria - sessions are durable execution records that can be resumed, forked, exported, and audited, and tools execute under policy governance with project-level extensions adding hooks and custom commands. The loushang.ai SDK routes across GPT, Claude, DeepSeek, Qwen, Kimi, GLM, and MiniMax with a model catalog, streaming, and cost tracking. The V1 product surface, loushang code, delivers this as a CLI and terminal workbench; later roadmap stages extend the same runtime objects to research workflows, team approvals, and a managed runtime. It is an actively developed solo project (roughly 1.3k stars) still in early V1.
