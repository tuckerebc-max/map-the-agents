Mentat from AbanteAI was a Python CLI coding assistant that synchronized git context automatically: it detected the current repository and branch and applied multi-file edits from natural-language instructions, with a companion VS Code extension. At its peak it drew roughly 2.5 thousand GitHub stars as one of the first open-source terminal coding assistants. The original CLI repository was renamed archive-old-cli-mentat and archived on January 7, 2025, with the Mentat name repurposed for a later product — an AI GitHub bot that wrote and reviewed code at mentat.ai. That successor is also gone: mentat.ai fails DNS resolution as of August 2026 and the original repo URL 404s. The entry stands as a historical harness whose lineage ended twice — first as a CLI, then as a GitHub bot.
