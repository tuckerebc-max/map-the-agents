## Description

Highlight (site page `what_makes_it_special`): Open-source AI agent that autonomously handles engineering tasks end-to-end

(captured site page body (agents/refactai.md), not a verified repo-code finding)
Refact.ai began as an open-source coding assistant built around fine-tunable code models and grew into an autonomous agent that plans and executes engineering tasks end to end — searching and analyzing a repository, integrating with GitHub, databases, CI/CD, Docker, and PostgreSQL. A 'digital twin' knowledge base accumulates context about your projects and workflow so the agent's suggestions and task handling adapt over time, and the agent runs with explicit user control over which tools it can invoke. It ships as IDE plugins (VS Code, JetBrains, Visual Studio, Neovim, Sublime) plus self-hosted and cloud deployments, with on-premise installs emphasizing privacy and custom fine-tuning on private code. Models range from built-in Claude and GPT options to BYOK Gemini, DeepSeek, and Grok. The company has announced that Refact Cloud is shutting down, so the self-hosted distribution is now the surviving path for its enterprise and privacy-focused users.
