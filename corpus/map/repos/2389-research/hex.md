## Summary (orientation draft, not independently verified)

Selected evidence records: Hex offers three modes: non-interactive print mode (e.g. hex --print with optional JSON output), an interactive TUI launched by running hex, and resume via --continue or --resume <id>. The CLI includes setup and doctor subcommands for configuring the API key and checking configuration health, plus an mcp subcommand (e.g. hex mcp add, hex mcp list) for managing MCP servers.
