## Summary (orientation draft, not independently verified)

HAL 9000 is a macOS dev-environment automation and AI coding agent configuration repository: an Ansible-driven setup CLI (`hal`), dotfiles, Claude Code/Codex configs, skills, and plugins. Contributor guidance in AGENTS.md/CLAUDE.md covers repo workflows only.
