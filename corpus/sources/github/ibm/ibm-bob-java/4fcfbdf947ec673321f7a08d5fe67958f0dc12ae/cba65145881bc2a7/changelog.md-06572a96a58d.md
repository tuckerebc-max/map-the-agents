# Changelog

All notable changes to the **Bob Java Premium Add-On** will be documented in this file.

## [1.0.0] — Initial Release

First public release of the Bob Java Premium Add-On for [IBM Bob](https://bob.ibm.com).

### Highlights

- **Java Upgrade** — Guided workflows for modernizing Java runtimes and applications.
- **Java Unit Test Generation** — Generate unit tests to support safer refactoring.
- **WebSphere to Liberty Migration** — Tools and recipes to accelerate migration from traditional WebSphere to Liberty.
- **UI Modernization** — Assistance for modernizing application experiences connected to Java backends.
- **Vulnerability Detection** — Identify known vulnerabilities in Java applications and dependencies to support safer modernization.
- **Java-aware Bob integration** — Java modernization mode, recipes, environment detection, and testing tools surfaced directly in the Bob experience.
