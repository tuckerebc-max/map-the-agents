# Changelog

All notable public-facing changes should be documented here once releases begin.

This project is in pre-release development.

## 0.1.1 - 2026-07-02

- Added the task workspace iteration, task authorization flow, and clearer task status handling.
- Added Mimo and Ark Coding provider support, advanced model parameters, and provider-aware context budgeting.
- Removed project index caching and project-level provider config from the current runtime.
- Improved session persistence, transcript chunk persistence, per-session backend write locking, and Windows responsiveness paths.
- Refined README release documentation and macOS ad-hoc signing configuration.

## 0.1.0-pre

- Initial source-level GitHub snapshot for Ore Code.
- Added repository entry documentation, contribution guide, security policy, support guide, code of conduct, privacy/data handling notes, known limitations, and a simple CI workflow.
- Continued macOS and Windows readiness work for the Tauri desktop application.
