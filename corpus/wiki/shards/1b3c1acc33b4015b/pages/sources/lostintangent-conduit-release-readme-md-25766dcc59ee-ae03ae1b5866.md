# lostintangent/conduit-release/README.md @ 25766dcc59ee

- Conduit is described as a workspace manager for parallelizing coding tasks with agents across local and cloud compute, organizing work as flexible tabs of terminals, editors, and browsers. [@claim:clm_07294b9bfc7a157d7b7983bc3941a0218078700df3215ccb3713b9eb2ca58e7a]
- Editor panes provide a file explorer and text editor with real-time git status, diffs, and stage/commit/push/pull actions, plus an integrated markdown preview. [@claim:clm_13fb206a4b1a2d28abdcc0f39bd194333ca778bc2fb04e7e42a54205bbd1987b]
- The project's stated assumptions include supporting multiple coding agents with a learn-once experience, staying close to the metal, treating terminals as central, and emphasizing composability and personalization with smart defaults. [@claim:clm_43aea20bc35442810522c008b1a5a0b3dec4d7cfa264b2bc39789ec61ea64282]
- Users can create isolated agent sandboxes by splitting terminals or duplicating tabs, with automatic git worktree management. [@claim:clm_47ce09b5cdcfce06eaba2f30f2ef46765d1278dd5d85342d44dfe123ff666365]
- Workspaces let users save and restore sets of tabs to move between projects easily. [@claim:clm_47ebc4fc9afe1c4048f450517e4a09e96c25c33a39743b00e4bfa34e816c64de]
- A `conduit` CLI lets users and coding agents design, interact with, and automate the dev environment, including terminals and browsers. [@claim:clm_5d16145fa958fe55207c130b48a720261f7410ab055da1085e41154c878c0891]
- The README frames the project as an exploration meant to be fun, questioning whether these primitives will suffice as coding agents grow more powerful. [@claim:clm_9345792f5e8b44e9789407a2070d9249283c2d31d3e282dd5316fd0b67db637b]
- Cloud terminals can be spun up and mixed with local terminals to parallelize tasks further. [@claim:clm_95242b21ac0c971ef2c24a1328c2bb2e49e43b5b214529bb7f1c6887ee40a98e]
- Clicking a URL in a terminal opens a browser pane for navigating, testing, debugging, and favoriting web pages without leaving the app. [@claim:clm_987d6c36310179eb30c9de532e5c2ed99fde3d78ac82c1fc38f63f2cb1bd2043]
- Coding agents can be defined and configured, then recalled via a slash command from any terminal. [@claim:clm_a0567c9c2fc662a908c1fadaeb54e05d74d485e9cbd0a24fa8f82033f34cdbc7]
- The latest release is distributed as a Conduit.dmg download and is currently macOS-only. [@claim:clm_a6aaaf366b8a0c71055a129766b4af55aba7560991c71389b482c445cf61174f]
- Tabs support a resizable, collapsible, clonable grid of terminal, editor, and browser panes, and tabs can be locked to prevent accidental changes. [@claim:clm_c735300e8d16be4bcdc83eebabe897673176ac5e959cd9f3c58150a5edd0894e]
- Multiple terminal panes can be synchronized so typing steers them all at once; a command palette (cmd+shift+p) offers global commands including quick terminals with an MRU list. [@claim:clm_f74c91c30d52a3f82f4c3274810a077424220d1f3dc6bb053dbcd47251bab8fe]
