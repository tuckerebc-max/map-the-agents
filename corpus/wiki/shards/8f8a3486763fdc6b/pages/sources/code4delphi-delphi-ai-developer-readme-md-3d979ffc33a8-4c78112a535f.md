# Code4Delphi/Delphi-AI-Developer/README.md @ 3d979ffc33a8

<!-- rcw:begin owner=source:src_f1105cbff9ba55fc8ba7d46063c42208 block=evidence -->
- The plugin aims to assist with generating and refactoring code, and offers suggestions in the IDE plus user-defined predefined questions to speed up searches. [@claim:clm_0eefad283aa7d81b7fe44994c4ed6e7e3b9041f36e0c9721ea8440423d5372cf]
- Online AI configuration offers a choice among Gemini, ChatGPT (OpenAI) and Groq APIs, with model selection, a key-generation link, and an API key field; Gemini and Groq are noted as free. [@claim:clm_19958d98d5b56af9fecc74a02ba18c1f2501edebf7117bcaf3131834eef0fe5c]
- A database chat lets users register databases, generate a structure reference, ask questions, execute the returned SQL, and view, copy or export results in a grid. [@claim:clm_28646df33be5940fac2ee4d31d371e03f5f8e2601d30254bdbd663e8f0fd5e95]
- Installation is done by opening Package\DelphiAIDeveloper.dpk in Delphi and installing the package; afterwards an "AI Developer" item appears in the IDE's main menu. [@claim:clm_72a231863161d9de5b6eb6c359d383f0cdca74f27d716e3cee3e844eb368927a]
- Users can set default prompts sent with every request to improve response quality, and can toggle modes where the AI returns only code or only SQL without comments. [@claim:clm_7465a5ec90899b9967a23e91eb936bd2942bae53120aa913e382611f3be9b78c]
- Repository development practice: contributions are welcomed via pull requests or by opening an issue in the repository. [@claim:clm_74fe267cbc997e95a6d0d45a7be5e70783db5427b95750cceed7e5a76f76c021]
- Offline AI relies on Ollama: users install Ollama, pick a model from its library, run "ollama run <name_model>", then configure the plugin's AI off-Line tab. [@claim:clm_765bca04a51544011d098dd1f8066fcf33271c4ad98fd8bc1f58d6caff593b6b]
- A Delphi IDE plugin, inspired by GitHub Copilot, that adds AI interaction to the Delphi IDE using the OpenAI, Gemini, Mistral and Groq APIs plus offline AI support. [@claim:clm_9dc938ff40ea5e4abf375ca5a25b751edb1e99b046887257495ff436f5b3c5bc]
- Both chats can optionally include the current unit's source code as prompt context; if code is selected only the selection is used, otherwise the entire unit. [@claim:clm_cfb0d9154ee90631def244b05f9d87c8cb19f30fb2adb98d17b34f4186b23323]
- A code completion feature can be toggled on/off, configured with a default AI, suggestion highlight color, and a shortcut (default Alt+Enter, requiring IDE restart); Tab accepts the suggestion. [@claim:clm_fa9c900706e0b7024505269586b0a09f8507374388a8ea842ffa0cfac8a19c90]
- An AI chat panel is opened via the "AI Developer" menu or Ctrl+Shift+Alt+A, with prompt and response fields, pre-registered questions, and actions to insert selected text at the cursor, create a new unit, or copy text. [@claim:clm_ff99b12755c1ec73e29cf6156a4d21fa90bd7abd49be9254cf62c683ea13d381]
