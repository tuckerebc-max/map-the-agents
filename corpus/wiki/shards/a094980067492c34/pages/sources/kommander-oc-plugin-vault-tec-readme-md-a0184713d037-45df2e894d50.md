# kommander/oc-plugin-vault-tec/README.md @ a0184713d037

<!-- rcw:begin owner=source:src_37166765ddd55702bf3498227fa5bf83 block=evidence -->
- The plugin is described as a Vault-Tec personality matrix that turns the coding terminal into a pre-War RobCo engineering assistant, including 122 vault experiment dossiers. [@claim:clm_0d008aa991c2abfdb3b99b03f39233ea63d33c1ca65d28c12a1677b337fe22a5]
- Installation is supported via the CLI command 'opencode plugin oc-plugin-vault-tec' or through OpenCode's Ctrl+P 'Install Plugin' flow. [@claim:clm_31d224b143cc978e4a1d4536bdc29f5da0f9b1f8a2823572f850b41f05adbed8]
- The plugin appears aimed at developers using OpenCode who want a Fallout-themed assistant persona and retro terminal UI theming rather than new tooling capabilities. [@claim:clm_5b9872d4a12dae2bd5df8ab87fa1414fbe82a17d400a9d18140828ebae8bad80]
- Plugin options are configured through the opencode.json and tui.json config files. [@claim:clm_996a79607239cd6e70a6bf7912e90ed66aed3d207d87dec675c7fadab9b22d36]
- TUI options cover enabled, theme (default 'vault-tec'), set_theme, scanlines, vignette (default 0.75), sidebar, and tips, all defaulting to true except vignette. [@claim:clm_aceaac6d100fc055ca0e5ed17c17ecf670920c16cb2905e16eb7d6ba3c29a504]
- Server-side options include enabled (default true), mode with append/replace values (default append), and an optional prompt override string. [@claim:clm_e7570c56aa9e53e5a04a003e03a71e8663424821fcd5091b3fe4563a6564296a]
