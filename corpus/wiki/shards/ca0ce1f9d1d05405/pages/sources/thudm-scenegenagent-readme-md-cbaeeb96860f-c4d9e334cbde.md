- SceneGenAgent is an LLM-based agent that generates industrial scenes through C# code, targeting precise measurements and positioning in industrial scene generation. [@claim:clm_5ba315d076d971c4378a0200c54b921bc1ca8f1071b8a769c9cad3a5b0609ded]

- SceneInstruct is a dataset built for fine-tuning open-source LLMs to integrate into SceneGenAgent; fine-tuned Llama3.1-70B reportedly approaches GPT-4o capability. [@claim:clm_9f77c4ee5da92ae207f527d497e5ae5d693d367e8d915597074bc7de0c5b644d]
