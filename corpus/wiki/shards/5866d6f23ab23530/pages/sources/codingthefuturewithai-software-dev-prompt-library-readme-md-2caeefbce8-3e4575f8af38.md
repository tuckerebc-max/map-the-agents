# codingthefuturewithai/software-dev-prompt-library/README.md @ 2caeefbce8d0

<!-- rcw:begin owner=source:src_d0649e3eb9165844986f6d1905e905f6 block=evidence -->
- Repository development practice: contributors are instructed to follow prompt guidelines, provide both .md and .meta.md files, test prompts across AI models and project types, and maintain language and framework agnosticism. [@claim:clm_0fdc1b68f55a864bc234d9514c42abdadae751e5091a309060342564a36f4d6a]
- Workflows are described as connected chains of prompts with defined input/output dependencies between phases, verification points for chain integrity, and progress tracking. [@claim:clm_2ce3f634547b7afeedfd6de36f5e58e65e4e56201244d648345401fa16db5042]
- The library is marked as a work in progress; the post-scaffolding sprint workflow prompts are described as the most rigorously tested, while many individual prompts are not yet part of a defined workflow or fully tested. [@claim:clm_2d1196673ede719abac486746d7e8517c9f2b0e8b7c7494beeb241a4c40c6eb3]
- Each prompt consists of two files: a .md file containing AI instructions and a .meta.md file containing usage documentation. [@claim:clm_90b8ec99fd3146e6318343fd5a1ead1dd0e427fdd7370ac699f88b89739f0686]
- The library targets AI-assisted software development across phases from project inception to maintenance, aiming for language- and framework-agnostic, modular, single-purpose prompts that chain together for complex tasks. [@claim:clm_e5fc2b3d0cd62cb37994037ff21be274a0a1808830cd40d2ce48a419c3f32327]
