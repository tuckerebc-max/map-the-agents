# traycerai/traycer/README.md @ b12949767727

<!-- rcw:begin owner=source:src_b4d174736d825f1fbe0e035035766015 block=evidence -->
- Supported coding agents listed as fully supported are Claude Code, Codex, Cursor, and OpenCode, plus Traycer's own native inference subscription. [@claim:clm_0e57e8738a6be0a0ed4f5d6a8bd6615bff103ba3dd1a8945f545be9c989a1bf8]
- Traycer is described as an AI orchestration app that runs multiple agents in parallel while sharing memory across all models and providers. [@claim:clm_1b33568fe926ea67cf93306ba8ce7c2d87deb94900dae16b10eadc450134ccec]
- Desktop builds are distributed for macOS (arm64 and x64 .dmg), Linux (AppImage, .deb, .rpm), and Windows x64 .exe via GitHub Releases. [@claim:clm_2c14b4e5828cd3462e071b73b16a80b387c562512346a94243b9836f038d1ffb]
- Agent-to-agent abilities such as reading a transcript or delivering a message are narrower and depend on the user, Host, and runtime, per a capability matrix. [@claim:clm_3adeef74486337eb88fe0290f71b09fdf88a4f496269034887ea72917a8185ce]
- The context window is shared across providers, so users can switch models within the same agent without losing context. [@claim:clm_5d566ebf3b2cc9cf44854006c0c434451d89ec3915437b48b3aff2d5e1b94e0c]
- The product supports agent-to-agent communication, letting users create automated loops where agents debate architecture or peer-review each other's code. [@claim:clm_7816c5179581b6c9c6eda32da210956dd8caec7136de7ebcca79c4d86ad0a5a1]
- Privacy documentation states code is processed in-memory and never stored or used for training, with a Privacy Mode defaulting on for Team plans. [@claim:clm_c7ed14339efd97dff1b26a7a3c3633906c97c0bfcca9bce95f8739e2a233e976]
- An agent is a durable session inside a Task that the user interacts with through a Chat or Terminal interface, powered by an underlying coding-agent provider. [@claim:clm_e7f4cdbcf9c202ddcaf3dde6c2e668e664a85710fcde72f22220bf9a60e1eb2c]
- The project is MIT-licensed open source with community channels on Discord, X, and YouTube, and accepts contributions under a DCO. [@claim:clm_ff6b7269561edf32772d284441145e3b286b6b4385983594aece2ab4b4bbb6af]
