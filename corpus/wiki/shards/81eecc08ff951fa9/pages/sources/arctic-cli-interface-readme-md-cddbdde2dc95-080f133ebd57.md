# arctic-cli/interface/README.md @ cddbdde2dc95

<!-- rcw:begin owner=source:src_373e1b691f3053b2ad26ed90c7d18c32 block=evidence -->
- Arctic runs locally and connects directly to the AI provider, storing conversations on the device; it collects anonymous telemetry that can be disabled with `arctic telemetry disable`. [@claim:clm_36aa835eccbeb33de090fd1f65b020c4fd5dcf74b5e29ce602d8ee9541f9a189]
- Arctic can import existing Claude Code and OpenCode configuration, including custom commands, agents from ~/.claude/agents/, and MCP servers. [@claim:clm_5c7feda44509064245b8bfd1c02d82823e959cd96ed24a6b71140f919da096ce]
- The product tracks real-time usage across coding plans, supports multiple accounts per provider, and allows switching models mid-conversation. [@claim:clm_75fb28875c3b4d5ff1f6b6d49361396a282f997681e36df9c5e5cf1fea0273af]
- API-key support is documented for OpenAI, Anthropic, Google, Perplexity, Openrouter, Ollama, and more. [@claim:clm_911156b2441482c831399754fd6d9e680fe03f40a9dabb74fcb44d9690b329ca]
- Arctic provides a terminal UI launched with the `arctic` command after a shell-script install and sourcing the shell config. [@claim:clm_98dcd33969fd5bc2764bd01a70073c184fd0439c9fb9a471540fb3e5148a7a76]

- Supported coding-plan providers include Claude Code, Codex, Gemini CLI, Antigravity, GitHub Copilot, Z.AI, Kimi, Amp Code, Qwen Code, and MiniMax. [@claim:clm_f45e44376081066ce05d24b04aaad65cf5bc56b68a3725465c607dc7147669e6]
