<!-- rcw:begin owner=source:src_787a3a41d26054129a7e0a923e602045 block=evidence -->
- The product ships desktop builds for macOS (Apple Silicon and Intel), Windows, and Linux, plus a mobile companion app for iOS and Android. [@claim:clm_202925405175482401d26c14910da83c83b5d9d6921152fe462526c188aad900]
- A single prompt can be fanned out across multiple agents, each in an isolated git worktree, so results can be compared and the winner merged. [@claim:clm_37cde1738016188a58e90000d89ed709edc933d541f2f655489b75a1c5e5d684]
- An Orca CLI exposes commands like `orca worktree create`, `snapshot`, `click`, and `fill`, letting agents script Orca workflows. [@claim:clm_63241f563ba2077441309619b30f724808f5dbcef9ce1c10d85a1747fc1b88a2]
- The repository includes a cloud relay under `cloud/` that pairs the mobile app with a desktop host, maintained as a separate pnpm workspace. [@claim:clm_9e76aed561c8db06169722ad9987bd090486ca18b9e7d6711967d0d2fcab9af4]
- The app includes a terminal feature with WebGL rendering, infinite splits, and scrollback that persists across restarts. [@claim:clm_ac2ef3e6c578df5114edf5d7de47b429eb7c3ad17f9c572c1dcc46a51a487777]
- Orca is a desktop application for running CLI coding agents such as Codex, Claude Code, OpenCode, or Pi side-by-side, each in its own worktree and tracked in one place. [@claim:clm_bb20dfae8e7cad11ae02d98cddf96e0600431d182f9192082f25bb9424cc7e37]
- Design Mode lets users click a UI element in an embedded Chromium window to inject its HTML, CSS, and a cropped screenshot into an agent prompt. [@claim:clm_bc2947b9664d981457989bf1ff3ea52d0fe606b29afd91a0e0a6b3640df27b57]
- The product supports running agents on remote machines over SSH with file editing, git, terminals, auto-reconnect, and port forwarding. [@claim:clm_bfe8027576c7bf2257c2c76969a76c4e534a25b82d40730c1b115d2af16ec101]
- A mobile companion app pairs with the desktop host to monitor and steer agents remotely, with finish notifications and follow-ups from the phone. [@claim:clm_c65beb4d2aa3a8a57c0e159fe83a9dee3ab5fbb506ff34838e793e44804c4709]
- Users can browse PRs, issues, and project boards in-app, open worktrees from tasks, and comment on diff lines to send feedback back to the agent. [@claim:clm_cdb8346deacf9660035b85392158964049c1a61365b179702725e2acfacd32ff]
