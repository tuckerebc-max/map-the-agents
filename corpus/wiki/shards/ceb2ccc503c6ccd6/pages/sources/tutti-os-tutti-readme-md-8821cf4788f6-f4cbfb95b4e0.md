# tutti-os/tutti/README.md @ 8821cf4788f6

<!-- rcw:begin owner=source:src_cee4c9f095265844987d82e9b396faa4 block=evidence -->
- Tutti includes an app center shared across the workspace with apps such as image generation (AI Canvas), prototype/UI-UX design, docs, and AI PPT, usable by both humans and agents, with app outputs remaining referenceable in the workspace. [@claim:clm_1f061d957120e1a8474a2bd8e1e1b52a519f732afad71bc7caa338910fa98a51]
- In open-source Tutti, agents run locally and working state stays local; in Tutti · VM, agents still run locally on the owner's machine inside a managed local VM while working state lives in a cloud Room. [@claim:clm_2db40593235f5a7dd7d81467d490644352a2fd9bade4a45e57f0afb460d61c55]
- Tutti is described as a real-time shared workspace where multiple agents share context, files, running tasks, and apps, positioned as a layer around existing coding agents rather than a replacement for them. [@claim:clm_34b660108d585b2c6f344ae01d6a5458d7bd66db70a7464d939eb4fa8ae9c97b]
- A goals-to-tasks feature lets users describe a goal, after which Tutti breaks it into sub-tasks that the user reviews and assigns to suitable agents. [@claim:clm_3d90a7e15eaf45b8fade2e805002dc60438a83c32b5b28b1be8ca47a8dc346a8]
- Agents from different providers share visibility into each other's work so they can avoid or resolve conflicts and decide whether work runs in parallel or in sequence. [@claim:clm_457615a89e0549a9295ad06d4a9be53f7a52aa4dc3db29a6a1684ee8f4fb6205]
- In Tutti · VM, sharing is scoped to the Room: only content created inside the same room is shared with invitees, and everything else remains private; creating a Room requires an invite code while joining does not. [@claim:clm_7422bb9f3e0d8d6283a0345d9b4dfb4250c39ecd8581759b7a063bc18242cdf5]
- The product is fully GUI-based with no command line, and offers a Control Center view surfacing agent conversations, pending approvals, and running tasks in one place. [@claim:clm_7e74dc362c4c07b22444cbcf9e1f21ae6e14bcf4c026a04fac55f1bee2b6929d]
- Tutti runs agents and apps on users' existing agent subscriptions rather than reselling model access; currently supported are Claude Code, Codex, and Hermes, with OpenClaw noted as in development, and a built-in free Tutti Agent during Early Access. [@claim:clm_ad8cc2e4923bbea755d8f62ad51badc2d31d2994a62d7bad16f51dbdc00840b7]
- In the agent chat box, users can @ past conversations, files, app invocations, and tasks — including those of other agents and, in VM, teammates — and use "+" to reference local files or app outputs. [@claim:clm_e0761c52348509524aa45a8e76efefa19c116797856c295bbd13128cf82b644e]
- The project ships two versions: an open-source Tutti for one person with multiple agents, and Tutti · VM (Early Access) adding group chat, multi-user collaboration, and work with others' agents. [@claim:clm_e0e42b10ce78f690bd0abe55cd20c3a9a189a936236fada96c83b8494d5fbfe6]
