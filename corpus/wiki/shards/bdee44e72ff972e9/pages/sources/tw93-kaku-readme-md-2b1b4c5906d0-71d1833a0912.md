# tw93/Kaku/README.md @ 2b1b4c5906d0

<!-- rcw:begin owner=source:src_384b174edd135bbfbb023def4505bb4a block=evidence -->
- The terminal provides documented keyboard shortcuts including Cmd+T (new tab), Cmd+D / Cmd+Shift+D (pane splits), Cmd+, (settings), Cmd+Shift+A / Cmd+L (AI panel and chat), and Cmd+Click to open URLs or file paths. [@claim:clm_581ecdcd0b2c7ac153f3ae241061af97bdea7abc8087d25c751dcab0c3b5c1a2]
- The `kaku` CLI includes subcommands such as `kaku init` for optional tool setup, `kaku --version`, `kaku ai` for AI service configuration, `kaku chat`, `kaku config`, and `kaku doctor`. [@claim:clm_623eb519f5c17b60dde57d4387cab802bf14f1e25d6e936c98f257d536c563c8]
- Kaku is an AI-friendly Mac terminal with sensible defaults, built on WezTerm with fonts, themes, shell integration, and Mac shortcuts preconfigured. [@claim:clm_6b8439813100ce27786af060f4c1938677a0ad6888c23dff683d9b760b81586b]
- Kaku bundles JetBrains Mono, built-in zsh completion, syntax highlighting, and directory jumping, and offers shortcuts for optional Lazygit and Yazi installations; it is derived from WezTerm. [@claim:clm_6fddb6db165884bd87f93d40c74a08e88c2c601afd7eefed68aff5f24454efcb]
- The AI assistant supports failed-command fix suggestions (applied with Cmd+Shift+E), natural-language `# <description>` to command generation, chat over terminal output and project files, and settings for tools like Claude Code, Codex, Gemini CLI, Copilot CLI, and Kimi Code. [@claim:clm_75e815d4850d769f47eb42bd35195d9ea02beab9605651e381cdd5d6e7b69614]
- Kaku is macOS-only; the FAQ states there is currently no Windows or Linux version. [@claim:clm_c03120c5222ce1198d97f2679ce8b7fba5dbfa0e04b455d57a4cf15dcac5b872]
- Kaku does not provide or relay the AI service itself; users must configure their own AI service via `kaku ai` to use the built-in assistant. [@claim:clm_e71f0622b4cfc55dbaf475e243ff2e2fc35d5609e3f6ac99b8889a650b07ec43]
- The product exposes WezTerm's Lua configuration system so users can customize fonts, themes, shortcuts, and terminal behavior; e.g. window transparency via `config.window_background_opacity` in `~/.config/kaku/kaku.lua`. [@claim:clm_f1dcfbe583ad4c9ca783e7ceed18125eee96eca1592ca89597e6a5a0d659bfdc]
