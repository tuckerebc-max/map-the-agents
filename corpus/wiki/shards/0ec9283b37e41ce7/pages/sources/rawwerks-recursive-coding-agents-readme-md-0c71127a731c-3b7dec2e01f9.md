# rawwerks/recursive-coding-agents/README.md @ 0c71127a731c

<!-- rcw:begin owner=source:src_04375187f52f59899b07578409753668 block=evidence -->
- The rubric directory includes an RLM definition, a seven-gate rubric, and a judging methodology document for evidence-based system judgment. [@claim:clm_5e0b569c37b01eaf2352f7477fcb236d8549bf8f1e98dfa99d6f5e8d204ec123]
- The repository contains four main parts: a SvelteKit web deck, an rlm-rubric directory, Claude Code workflow examples, and OpenProse program examples. [@claim:clm_818a0386e1685d777421725e5856dc32aae5fc72915f90643751edc4bb8a9634]
- The repo defines Recursive Language Models (RLMs) as systems that keep context as symbolic state, inspect and slice it with code, call models or agents over slices, and aggregate results verifiably. [@claim:clm_8d390bb8f8460d636fcdc11861db6754deaa2fc587ce513a57953e3e087f7529]
- A one-line RLM definition states the task context moves into a persistent executable environment, the root model works through handles, and final answers return through the outer model-call interface. [@claim:clm_96d149639f2c716d58f9ad730264ea548c90312f03a5e88148c4a9873d7e3dfd]
- Example folders are verdict-shaped: files under rlm/ are passing or intended-passing examples, while not-rlm/ holds nearby negative controls. [@claim:clm_a0fd590c6161d104aba847c616fe6c38c5e4f983986fb8d75de79c7c904a366a]
- Judging is by run shape rather than product label: a full RLM requires externalized context behind handles, model-chosen decomposition, programmatic calls over slices, and symbolic aggregation. [@claim:clm_bd9f11e1326185da122390fd41494ec98e5fb591598035e49fcac6aad8ee44a3]
- The live presentation is a website at https://recursivecodingagents.com, described as the public deck for the AI Engineer World's Fair 2026 talk. [@claim:clm_f63be282c293b048dd3cf6658694a13c3baffccb798897157a3630994c5563ab]
