# pingdotgg/t3code/README.md @ 66e39ca2aabd

<!-- rcw:begin owner=source:src_13b626322380593d98ae2b47f7da50de block=evidence -->
- Running `npx t3@latest` launches the T3 Code backend on the local machine plus a local web app for controlling agents; a `--help` flag exposes the full CLI reference. [@claim:clm_367ea2af261c8f52680fdfb981124361c6ced9fbf1ce390fc00f91e4c1cddcd6]
- T3 Code lets users control coding agents remotely through an iOS app, Android app, web app, and an Electron-based desktop app. [@claim:clm_56216ed74264ad1203570acd775ac246facc74a89f9ffb826afb5979b8062800]
- The desktop app is distributed via GitHub Releases and package registries including winget (T3Tools.T3Code), Homebrew cask t3-code, and AUR packages for both stable and nightly builds. [@claim:clm_5d183be87510a17766de246b4015947eeb2d86f103231fe7efb8103634ce1d88]
- The product works with existing subscriptions to Claude Code, Codex, Cursor, Grok Build, OpenCode, and Google Antigravity, controlling those agents when set up on the user's computer. [@claim:clm_a90ec8c4f5a55439ecb62a29a8960a915bda536db9df6524c074f5abfb3c5a11]
- At least one provider must be installed and authenticated before use; each provider names a CLI and login command, while Antigravity is enabled in Settings with Google sign-in and needs no CLI. [@claim:clm_c506279bb5c893287914e4cd0173e9cb6bf7032827dc32809f4e5d070cb634ad]
- The install-free server mode requires Node.js 22.16+, 23.11+, or 24.10+. [@claim:clm_e8c4185acbf2aaa06a34f53a4d82017e1b0ef100debb00a923b0907c3b550169]
- The project charges nothing for the product and states it aims to be performant, remote-ready, and open enough that users can fork and build their own editor. [@claim:clm_f654f61bea6cd3c806d7085c4563465f094f8acecc114e9b31f4151746ebf036]
