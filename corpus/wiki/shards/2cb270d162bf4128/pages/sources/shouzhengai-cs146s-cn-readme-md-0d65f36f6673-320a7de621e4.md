# ShouZhengAI/CS146S_CN/README.md @ 0d65f36f6673

<!-- rcw:begin owner=source:src_621eb6109a2a53da81e570e927e63d69 block=evidence -->
- The repo presents a Chinese version of the CS146S course aimed at helping people get started with vibe coding, and is described as unofficial with content credited to the original course provider. [@claim:clm_162a4de9a372ed9d5863ae3853d4dadb6d83aa50207748ad7fda1625624580a8]
- The course is not tied to a specific language; examples mainly use Python and JavaScript, with some systems languages where appropriate. [@claim:clm_1ffdca08a0af7dea53bf95cf73bd08936594f84d6628e5ffa3c10965e94598b5]
- The Fall 2026 schedule includes week 1 on coding agent internals (agent loops, core tools like read/write/edit/bash, system prompts) and week 2 on context engineering, RePPIT, and MCP. [@claim:clm_524d7aefae4f4b222d8cfef94541ba4f251110974f54bb8fe1f252fc0aa08c37]
- The course format includes weekly lectures, hands-on coding sessions, and industry guest talks, with a final project demonstrating modern development practices. [@claim:clm_6b5b6919d8d38c87b8bbca3229994c37183024087ab576974cd6479b42b12fc6]
- Prerequisites are programming experience at roughly the CS111 level, with CS221/CS229 knowledge recommended rather than required. [@claim:clm_748a89fce1c02c59adc99f021ccbe05d4d53307d1f9d19cebd5eb6c9a42c5057]
- Expected workload is about 10-12 hours per week including lectures, assignments, and project work. [@claim:clm_7d26517556578c4b5156026b178e68a9e757054d8abe5f481b8b67944788ebe7]
- Students need a computer running modern development tools; some cloud services such as GitHub Copilot may require subscriptions, though the course will provide access or alternatives where possible. [@claim:clm_85c26e3fafe2b7e6975db66f5cb779aab60b36d15dccedb94264d7e7b72824fd]
- The course covers emerging AI-native software development practices including MCP, Agent Skills, spec-driven development, loop engineering, and the software factory concept. [@claim:clm_96899baaa7eba154be14c8eb3cd44102ef0caebaa169e7f809d54c789d5bd8aa]
- Repository development practice: the project is long-term maintained and welcomes stars, sharing, and pull requests from contributors. [@claim:clm_99152910b8313d74f3c2f02cfc99388b0ded75c6a61d89e38caf67ff308ec659]
- The project is distributed under the MIT license, with details in the LICENSE file. [@claim:clm_ebe8596407205596c53d5aee9a02909cb7f0d3ed1c092d676d57a7c1dc43cdf5]
- Grading is specified as 50% final project, 15% weekly assignments, 5% open-source contribution, and 5% class participation. [@claim:clm_f92e241ec6739f4d718c5cabfc3cc1ad13c1831462a90791fc944169c413d88d]
- Auditors (Stanford students and staff) may attend all lectures, but their assignments will not be graded and no final-project advising is offered to them. [@claim:clm_fd05afef569e6a0c5b67cc35b34cbe092f382051b505fa21826c7a1db0c527e5]
