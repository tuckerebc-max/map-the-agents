# wendy7756/vibe-coding-guide/README.md @ 96368d319e86

- The repository is a bilingual guide (Chinese README with an English README_EN.md) explaining the 'Vibe Coding' approach to AI-assisted programming. [@claim:clm_26f4f802030a00e9378384d0a18765b2a7ad540d4b2c385539b486bbe992be45]
- The guide defines Vibe Coding as collaborative programming where developers describe requirements in natural language and an LLM generates complete runnable code, refined through iterative feedback. [@claim:clm_29010b3ec9b8fdc41108b8d357a644cc099d70db0d7d260c32bedbd40ea04835]
- It attributes the Vibe Coding concept to Andrej Karpathy, described as an OpenAI co-founder, introducing it in early 2025. [@claim:clm_57653ba77035264642333564195910d7622465a269d4ffbffb0ea82bfd9d16a0]
- A troubleshooting section lists common problems with AI-generated code: poor code quality, loss of conversational context, and over-reliance on AI, each with suggested mitigations. [@claim:clm_6f1ad71222c83fbae6fb8acdb172706d250e2f705d744008d7fb50d5bd8680ff]
- It catalogs AI programming tools across categories including mainstream assistants (GitHub Copilot, Cursor, Claude Code), extensions (Cline, Roo Code, Tabnine), no-code builders (Lovable, Bolt.new, v0.dev), and cloud IDEs (Replit, CodeSandbox, Gitpod). [@claim:clm_8e1b099c6e5ec73723375ce2f5a2cff4a5ba30c5c6c9507f2b12cb66ebb2c51f]
- The author states they have no coding background yet built six iOS apps and two open-sourced websites in three months using ChatGPT and Cursor, motivating the guide. [@claim:clm_9c2abb92e6934be995fc57b1348a2c755d0d3cee1a29ed39fff78944fa88b96d]
- The guide describes a five-step iterative core workflow: natural-language input, AI code generation, execution and observation, feedback and refinement, and an iteration loop. [@claim:clm_9d1941c4454a3eb72d43865461f5a00a6c447119efd476e100cd9dae829d381a]
- Best-practice sections advise writing specific prompts that state the tech stack, constraints, and expected results, and developing iteratively in small steps while referencing earlier code for context. [@claim:clm_a0d53af0e08aa638a55c2cbd01f9c7f913bd52398d374eb388ee013fb2c62ef8]
- The guide lists underlying LLMs it considers foundational to Vibe Coding, including GPT-4/GPT-4o, Claude Sonnet, and Gemini Pro. [@claim:clm_aaa2ceb318fdaad9b3a6b6fe79408c85eb6c80d00fedf1f07ad5ff1bdd6c2d62]
- A references section cites academic works on code generation (e.g., Codex evaluation, AlphaCode, CodeGen, Code Llama) plus industry reports and official tool documentation. [@claim:clm_acd68b8339c141b0b9387dcc3d222780a5b0fb6d364307293b17f59494527528]
